# ITD140 - Group vs. Individual Fairness (interactive lesson)

Static export of the interactive fairness lesson: four interactive widgets (demographic-parity explorer, equalized-odds explorer, individual-fairness / Lipschitz demo, and a group-vs-individual trade-off) plus self-check questions for each subtopic. Hosted on GitHub Pages and embedded into a Canvas page via `<iframe>` (see `canvas_fairness_page.py`).

This repo is SEPARATE from the Codespaces workspace repo that generated it; it exists only to host the lesson on GitHub Pages.

Generated by `export_fairness_for_github_pages.py` - edit `fairness_lesson_content.py` in the workspace repo and re-run to update `index.html`; don't edit `index.html` directly.

**Note:** GitHub Pages sites are public by default, and the self-check answers live in client-side JavaScript (`data-answer` attributes), so anyone viewing source can see them. Treat these as practice checks, not secure assessment - keep graded quizzes in Canvas's native Quizzes.
